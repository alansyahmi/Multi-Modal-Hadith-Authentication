CHAPTER 1

Introduction

Core Challenge

  • Hadith authentication via sanad criticism — cornerstone of Islamic scholarship
  • ʿIlm ar-Rijal evaluates narrators for ʿadāla (moral probity) & ḍabṭ (mnemonic precision)
  • Over 500,000 narrators tracked historically through manual processes
  • Digital collections growing too large for unaided human review — a scalability crisis

The Digital Gap

  • Two complementary datasets: Sanadset 650K (chains, no grades) + HuggingFace hadith_datasets (grades, no chains)
  • Alignment bridges this gap — linking sanads to ground-truth grades
  • Critical need for an automated, scalable solution preserving classical methodology

Goal: A reproducible, inspectable decision-support tool grounded in classical Jarḥ wa Taʿdīl principles — combining Arabic NER, Graph Neural Networks, and Semantic Sentiment Quantisation.

1.2

Problem Background

Traditional Bottlenecks

  • Manual cross-referencing of thousands of biographical entries across vast corpuses (e.g., Taqrīb at-Tahdhīb, Tahdhīb al-Kamāl — 36 volumes)
  • Arabic orthographic ambiguity — minor name variations lead to misidentification across manuscript traditions
  • Temporal & geographical verification complexities

Critical gap: No end-to-end automated reliability scoring system exists that preserves classical methodology while enabling digital-scale analysis.

Hadith Structure

  • Sanad — chain of narrators (who told whom)
  • Matn — textual content (the saying/action)
"...from Mālik, from Ibn Shihāb, from ʿAlī ibn Ḥusayn, that the Prophet ﷺ said: 'Part of the excellence of a man's Islam is that he leaves what does not concern him.'"
— Muwaṭṭaʾ Mālik, Book 47, Hadith 3 (Ṣaḥīḥ)
1.3

Problem Statements

PS1 — Lack of Quantified Reliability

  • Current NER models extract and disambiguate names but cannot judge narrator standing
  • No existing framework maps Jarḥ wa Taʿdīl assessments → standardised reliability index
  • Identifying a narrator is insufficient — the framework must evaluate trustworthiness from historical evidence (Ahmad et al., 2025)

PS2 — Graph without Reliability Scores

  • Transformer models extract chains as graphs (Mosa, 2025; Oumer, 2025)
  • But stop at graph construction — no reliability scores assigned to narrators
  • No use of actual Jarḥ wa Taʿdīl terms to judge trustworthiness within the graph

This research goes beyond: Adds a quantitative reliability index (0.0–1.0) + GNN-based structural analysis — combining NER extraction, KG construction, GNN analysis, and sentiment scoring in one integrated pipeline.

Research Objectives

O1

Semantic Sentiment Integration

Develop a Transformer-based NLP model utilising semantic sentiment analysis to map qualitative scholarly judgments from historical biographies to a standardised quantitative reliability index (0.0 – 1.0).

O2

GNN & Knowledge Graph

Construct a multi-relational Knowledge Graph of narrator transmission networks and leverage GNNs to evaluate structural topology alongside temporal and geographical features as contributing factors to chain plausibility.

O3

Evaluate the multi-modal framework's verification accuracy by benchmarking automated hybrid reliability scores against canonical ground-truth chain-level Hadith gradings (Ṣaḥīḥ, Ḥasan, Ḍaʿīf).

Research Gaps

The Disciplinary Split

  • Text NLP models extract entities but discard graph-structural properties (Alghamdi et al., 2025)
  • Graph architectures evaluate topology but strip semantic qualitative data from biographical texts (Mosa, 2025; Mahmoud et al., 2024)
  • No study unifies both dimensions simultaneously

Missing End-to-End Pipelines

  • Oumer (2025): output is a graph, not a graded Hadith

Evaluation Standardisation Deficit

  • No shared benchmark protocol exists for assessing end-to-end grading accuracy against Kutub as-Sitta ground-truth (Farooqi et al., 2024; Mahmoud et al., 2022)
  • This project establishes such a protocol

3.3

Stage 1: Data Ingestion & Preprocessing

Ingestion Data Sources

  • Biographical: Ibn Hajar's Taqrīb al-Tahdhīb & al-Mizzi's Tahdhīb al-Kamāl (Shamela Library).
  • Transmission: Sanadset 650K (650,986 chains) aligned using pre-alignment targets (1,800 & 7,000 queries) to capture ground-truth grades.

Biographical Text Parsing

  • Custom regular expression parser isolates independent text blocks using structured markup delimiters (e.g., `# $Tarjama`).
  • Strips headers, page numbers, and footnotes to yield clean, consonantal Arabic text blocks.

Two-Tiered Algorithmic Alignment

  1. Tier 1: Heuristic Space Reduction
    Character-level n-grams (n in [3, 5]) + TF-IDF cosine similarity. Reducer isolates Top-10 candidates, cutting the search space by 85%.
  2. Tier 2: Lexical Verification
    Fuzzy sorting via token-sort Levenshtein distance (`RapidFuzz`). Candidate matches must pass similarity threshold t ≥ 0.95.
  3. Ancestral Node Tie-Breaking
    Resolves identical lexical ratios by checking teacher/student connection overlaps against the biographical graph.
  4. Preservation & Audit Log
    Generates SHA256 keys of normalized skeletons for uniquely matched names. Sends failures to a JSON quarantine log for manual audits.

Algorithmic Name Mapping

  • Root-based matching isolates consonantal skeletons.
  • Fuzzy name skeleton matches (Levenshtein distance ≤ 2).
  • Resolves an average of 3.2 alias forms per canonical narrator.

Node & Edge Attribute Representation

  • Tabaqa (Generation): Coded as integers [1–12] matching Ibn Hajar's chronological levels, tracing from Companions (~1st C. AH) to compilers (~3rd C. AH).
  • Geographic Traveled Cities: List of cities visited historically (e.g., Medina, Kufa, Basra, Damascus, Baghdad, Cordoba) parsed from biographies.
  • Relational Edges: Directed links mapping teacher-to-student propagation (u → v).

Note: Due to a lack of verified sequence F1 metrics, token boundary classification via fine-tuned AraBERT sequence labelers is demoted to future work. Boundary extraction is heuristic-driven.

3.5.1

Stage 3: Semantic Sentiment & Jumhūr Aggregation

Ordinal Classification Design

To prevent Deep Imbalanced Regression (DIR) score compression toward the empirical mean, the task is formulated as a 5-class ordinal classification (discrete bands) instead of continuous regression.

Classifier predictions map qualitative Arabic assessments directly to ordinal class ranges from Class 0 (abandoned) to Class 4 (highly reliable).

Consensus Variance Rating

Measures agreement among classical scholars by normalizing rating variance:

agreement = 1.0 - Var(s) / 0.16
Model Tier Arabic Synonyms Score (s_i) Academic Explanation
Thiqah (Class 4) ثقة, ثبت, حافظ, إمام 0.85 Max textual reliability. Bounded limit.
Ṣadūq (Class 3) صدوق, لا بأس به 0.70 Truthful but susceptible to minor error.
Maqbūl (Class 2) مقبول, صدوق يهم 0.40 Acceptable only when corroborated.
Ḍaʿīf (Class 1) ضعيف, لين الحديث 0.15 Unreliable or weak transmitter.
Matrūk (Class 0) متروك, كذاب, وضاع 0.05 Abandoned transmitter (minimum baseline).
3.5.2

Stage 3: Graph Autoencoders (GAE) for Topology

GCN Encoder Architecture

A 2-layer Graph Convolutional Network (GCN) encodes neighborhood topologies into 64-dimensional latent node embeddings (Z) from the adjacency matrix (A) and features (X):

Z = GCN(X, A)

Inner Product Decoder

Reconstructs the graph's links via dot product. It outputs link compatibility probability for any teacher-student pair:

Â_u,v = σ(z_uᵀ z_v)

Self-Supervised Link Prediction

  • Trained for 200 epochs using the Adam optimizer to minimize Binary Cross-Entropy on link existence.
  • Achieves robust performance on a 20% test split:
    ROC-AUC: 92.39%  |  Average Precision (AP): 94.04%.

GNN Uncertainty Modulation

For transmitters classified as weak but showing high structural integration (GNN anomaly score < 0.25), a GNN mitigation factor reduces the base weakness discount:

d_i_mitigated = d_i + (1.0 - d_i) * 0.15 (15% Max Mitigation)

Stage 3: Chain-Level Aggregation & Modifiers

Modulated Narrator Score (W_i)

Risk Type Arabic Root Pattern Multiplier
Tadlīs (Concealment) تدليس, مدلس, يدلس 0.80
Ikhtilāṭ (Deterioration) مختلط, اختلط بآخره 0.50
Jahālah (Identity gap) مجهول العين, مجهول الحال 0.30
Kadhib (Fabrication) كذاب, يضع الحديث 0.00

Soft Aggregation (S_base)

Balances the weakest-narrator bottleneck with overall chain quality to prevent exponential score decay:

S_base = α * min(W_i) + (1-α) * mean(W_i)

Chain-Level Edge Penalties

  • Ambiguous (P_amb): Penalty if *Mudallis* transmits using *"عن"* (ʿan, from).
  • Temporal (P_temp): Gap penalty (0.40 or 0.60) if teacher is chronologically younger or generation gap occurs.
  • Geospatial (P_geo): 0.85 multiplier if teacher-student city distance exceeds 3,000 km.
  • GAE Path (P_gnn): 0.85 multiplier if link probability falls under 0.25.
Final Calibrated Chain Score: S_chain = S_base × P_amb × P_temp × P_geo × P_gnn

5.4

Discussion & Theoretical Ceiling

The Sanad-Only Ceiling (Balanced 3,022 Experiment)

Proven by testing the pipeline on a grade-balanced dataset (1k Ṣaḥīḥ [2], 1k Ḥasan [1], 1k Ḍaʿīf [0]) to eliminate majority bias:

  • Ṣaḥīḥ [2] Recall (87.1%): Strong structural detection rate for clean chains.
  • Ḥasan [1] Recall (0.9%): Cannot distinguish Ḥasan [1] from Ṣaḥīḥ [2] — both have equally sound sanads.
  • Ḍaʿīf [0] Recall (18.1%): Fails to catch weak Hadiths when their transmission chains are structurally flawless.
  • Balanced Accuracy (35.2%): Converges near the 33% chance baseline — not a pipeline deficiency but a validation of the pipeline's honesty: it does not overfit to produce artificial confidence on an impossible task.
Performance vs. Theoretical Ceiling

Epistemological Explanation

In classical Hadith theory, a clean sanad is a necessary but not sufficient condition for authenticity. Many Ḍaʿīf grades are triggered by matn-level defects (hidden textual inconsistencies / ʿilal or historical contradictions / šāḏ).

Since matn analysis is out of scope for a sanad-only system, these defects are mathematically invisible to the model, imposing an inherent epistemic ceiling of ~65% on real canonical collections.

Geospatial Validation: 0 geographic violations in Kutub as-Sittah (1,781 chains) vs 132 in bulk 435K (0.03%) — classical compilers already verified regional overlap, so this penalty is passive on canonical text but activates effectively on noisier corpora.

CHAPTER 6

Conclusion

Research Summary, Limitations, and FYP2 Roadmap

6.1 Contributions & Limitations

Successful delivery of PO1, PO2, and PO3 objectives, and analysis of boundary constraints like network cold-start and sanad-only ceilings.

6.2 Recommendations & FYP2 Roadmap

A three-part engineering strategy to resolve limitations through Transformer NER, Relational GNNs (RGCNs), and matn-driven corroboration boosts.

6.1

Summary of Project Contributions

PO1: Semantic Sentiment Quantisation

Bypassed continuous regression score compression using a fine-tuned AraBERT v2 5-class ordinal classifier. Balanced the dataset to 1,116 samples per class, yielding a Macro F1-score of 0.85 and Quadratic Weighted Cohen’s κ of 0.87. Map qualitative Jarḥ wa Taʿdīl terms to continuous trust weights on a historically bounded interval of $[0.05, 0.85]$.

PO2: KG & Representation Learning

Constructed a scale-free network mapping 262,497 narrator nodes and 987,036 transmission edges. Trained an unsupervised Graph Autoencoder (GAE) achieving a link prediction ROC-AUC of 92.39% and Average Precision of 94.04% to verify edge plausibility.

PO3: Chain-Level Aggregation & Evaluation

Developed a parameterised soft aggregation pipeline ($\alpha=0.50$) integrating biography-derived narrator scores with structural, temporal, and geospatial edge penalties.

Stable discriminatory power: Achieved an overall accuracy of 60.13% on clean, book-balanced canonical collections, peaking at 72.11% accuracy on the highly rigorous Ṣaḥīḥ al-Bukhārī corpus.

This confirms that research objectives PO1, PO2, and PO3 have been successfully achieved, establishing a solid baseline for isnād validation.

6.2

Key Limitations & Structural Insights

The Sanad-Only Classification Ceiling

On the artificially balanced grade dataset, accuracy dropped to 27.08% with near-zero agreement metrics ($\kappa \approx 0.00$). This behavior confirms a fundamental limitation: transmission network analysis alone cannot distinguish between grades when the transmission structure itself is flawless. Many traditions are weakened due to matn (textual body) anomalies or hidden defects (ʿilla) rather than narrator untrustworthiness.

Passive Spatiotemporal Layers

Ablation testing revealed that geospatial and temporal guardrails remain completely passive (multiplier = 1.0) when processing clean canonical text corpora, as classical compilers engineered these works with zero physical or chronological inconsistencies. However, their activation on synthetic anomaly injection sets boosted accuracy from 54.35% to 84.65%, validating their role as critical security features for noisier text environments.

The Graph Cold-Start Phenomenon

Explicit textual evaluations in classical biographical dictionaries are concentrated heavily on an elite tier of transmitters.

Consequently, 91.44% of total nodes in the 262K network defaulted to the neutral GNN fallback score of 0.30 due to attribute sparsity.

This reveals that the framework operates primarily as a selective lookup and verification mechanism rather than an open feature propagation engine under the current dataset parameters.

6.3

Recommendations for Future Work (FYP2)

Objective 1: Reliability Index Refinement

Replace the heuristic token extraction used in the preprocessing stage with a native, fine-tuned Transformer-based Named Entity Recognition (NER) pipeline. This will automate the boundary parsing of complex name lineages (ism, kunya, nisba) directly from unaligned Arabic text blocks to ensure cleaner data ingestion.

Objective 2: Knowledge Graph Optimization

Deploy Relational Graph Convolutional Networks (RGCNs) to systematically resolve the Graph Cold-Start Phenomenon, shifting the 91.44% macro fallback nodes from static default values (0.30) to learned, dynamically propagated structural embeddings.

Objective 3: Chain Grading Verification

Implement a matn-driven chain corroboration layer. Rather than analysing the semantic content of the text (which remains strictly out of scope), this layer will use text deduplication and similarity clustering to identify identical or near duplicate matns that are transmitted via entirely separate, independent chains.

In traditional scholarship, finding parallel tracks (mutābaʿāt) structurally upgrades the reliability profile of marginal narrators.

Integrating this feature will allow the GNN framework to dynamically apply corroboration boosts to chain scores, safely clearing the sanad-only classification ceiling without entering content-based critique.
