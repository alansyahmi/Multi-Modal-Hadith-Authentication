# Frozen v4 Codebase for the Progress Report

This folder contains the report-centered v4 implementation and selected evidence for the frozen presentation version.

## Start here

1. Read the [implementation walkthrough](docs/CODE_WALKTHROUGH.md).
2. Use the [code map](docs/CODE_MAP.md) for file entry points.
3. Read the [bundle manifest](FYP2/V4_BUNDLE_MANIFEST.md) for provenance and reproduction limits.
4. Open the selected [v4 report](FYP2/report_draft/fyp2_report_v4_final.pdf).

The staged prototype is split across run_stage1.py, run_stage2.py, and run_stage3.py. PO1, PO2, and exploratory PO3 are separate benchmark workflows. Their outputs are not all produced by running the three stage commands in sequence.

This is a report-centered reconstruction of the frozen v4 implementation evidence, not a bit-for-bit copy of the source state at submission.
