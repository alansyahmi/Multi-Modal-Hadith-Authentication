# FYP General Guidelines & Compliance

## Overview
This skill file contains instructions for aiding the user in maintaining compliance with university FYP requirements, maximizing marks, and ensuring an impactful final outcome.

## 1. FYP 1 Deliverables & 70% Completion Target
To hit the 70% FYP 1 completion target for high marks, ensure the following milestones are aggressively pursued:
- **Chapter 1 & 2 (Introduction & Literature Review)**: Completed and polished.
- **Chapter 3 (Methodology)**: Clearly defined algorithms, data sources, and system architecture.
- **Initial Prototype**: Core data ingestion and a baseline NER model or Knowledge Graph schema should be functional.

## 2. Logbook Maintenance Template
When assisting with logbook entries, use the following structured format to ensure they are actionable and verifiable for the SV (Supervisor):
- **Date & Week**: (e.g., Week 4, 12th Oct)
- **Tasks Planned**: What was the goal for this period?
- **Actual Progress**: Detailed tasks accomplished (e.g., "Cleaned 1000 sanads from AR-Sanad").
- **Challenges / Roadblocks**: (e.g., "Arabic text encoding issues").
- **Next Steps**: Actionable tasks for the upcoming week.

## 3. Publishability Checklist
To ensure the project can be spun off into a published article:
- **Novelty**: Must push beyond mere narrator disambiguation. The "Probabilistic Trust Scoring" is the novel contribution here.
- **Rigorous Evaluation**: Every NLP claim must be backed by quantitative metrics against a baseline.
- **Reproducibility**: Source code, datasets, and experiment seeds must be documented thoroughly.

## 4. Meetings & SV Presentations
- Before SV meetings, compile a brief "Progress vs. Plan" summary.
- Focus discussions on tangible UI/system progress and metric improvements (e.g., "Our NER F1-score improved from 0.70 to 0.85").
